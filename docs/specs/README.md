# Specs

One file per change, `OJ-<n>-<slug>.md`, created from `TEMPLATE.md` (the `/spec` skill does this). A spec is approved by the owner before implementation starts and set to done in the PR that completes it. Specs are the memory of the project: when a question comes up about why something works the way it does, the answer should be here or in `docs/adr/`.
